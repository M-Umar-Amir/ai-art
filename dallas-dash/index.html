How the reward works

  • Play and make progress. Each run is verified server-side before the points land. Progress builds across sessions.
  • Claim the reward. At 100,000 points, claim once: the points are deducted and a code is issued in the same step.
  • Choose food and enter the code. Use the same account in the food app and type the code at checkout.
  • Place the order. The restaurant funds the discount and fulfils the order.
  • Handle problems fairly. If the restaurant cancels, the coupon returns with its original expiry.
