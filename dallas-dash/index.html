How it works

  1. Run. Every run is replayed and verified before its points count.
  2. Claim. At 100,000 points, claim: the points are deducted and a one-time code is issued.
  3. Order. Sign in to the KFC app with the same account and enter the code at checkout.
  4. Redeem once. The code is reserved for that order and used up when it's paid. If the restaurant cancels, it comes back.
